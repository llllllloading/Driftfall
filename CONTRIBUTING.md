# Contributing to Driftfall

Thanks for your interest in Driftfall.

## Current Focus

The project is currently in active prototype development. The most useful feedback and contributions are related to:

- combat feel
- ability clarity
- round pacing
- upgrade readability
- strategic diversity
- UI/UX improvements
- bug reports

## How to Contribute

You can help by:

- reporting gameplay bugs
- suggesting combat improvements
- proposing ability ideas
- giving feedback on match pacing and readability
- improving documentation

## Setup

1. Clone the repository
2. Open the project in Godot
3. Run the main scene
4. Test the current prototype locally

## Guidelines

- Keep changes focused and easy to review
- Prefer readable and modular gameplay logic
- When suggesting mechanics, explain the player-facing goal
- Document important changes in pull requests or issues

## Feedback

If you are sharing feedback, the most helpful format is:

- what happened
- why it felt good or bad
- what decision it affected
- how you think it could be improved
