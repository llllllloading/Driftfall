# Driftfall

Driftfall is a fast-paced multiplayer arena combat prototype focused on knockback-based PvP, round-based upgrades, shifting safe zones, reactive abilities, and high-tension positioning.

Instead of dealing traditional damage, players outplay each other by forcing movement mistakes, controlling space, surviving arena pressure, and exploiting timing windows with skill-based abilities.

## Vision

Driftfall explores a competitive design space between party brawlers, tactical arena games, and ability-driven PvP systems.

The goal is to create a multiplayer game where:
- mechanical precision matters;
- positioning is more important than raw damage numbers;
- ability choices shape playstyle between rounds;
- arena pressure constantly changes player decision-making;
- even a less upgraded player can still win through better execution.

## Core Gameplay Loop

Each match is built around short, high-pressure rounds:
1. Players spawn around the arena edge.
2. They fight using movement, knockback abilities, traps, defensive tools, and environmental pressure.
3. The arena shrinks over time and the center may shift, forcing repositioning.
4. Players earn progression between rounds and draft upgrades.
5. Over multiple rounds, builds diverge and combat becomes more layered and expressive.

## Current Features

- Knockback-based combat instead of traditional HP damage races
- Fireball as the main skill-shot pressure tool
- Dash for repositioning, escapes, and aggressive engages
- Mine-based area denial and trap pressure
- Reflect Shield for timing-based defensive counterplay
- Round-based upgrade drafting
- Random powerups that change match tempo
- Shrinking arena pressure
- Rescue timer when falling outside the arena
- Increasing vulnerability system for chained knockback pressure
- Playable bot opponents for local combat testing
